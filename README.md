# Job Application Tracker

A personal job application tracking system built using **Microsoft Excel** and **Microsoft Power Automate.

## Project Overview

This project helps track job applications and automate reminders for applications that are still under review or awaiting a response.

## Technologies Used

* Microsoft Excel
* Microsoft Power Automate
* Power Automate cloud flows

## Features

* Record job applications
* Track application status
* Store company and job information
* Track application dates
* Send email reminders using Power Automate

## Application Statuses

* Applied
* Under Review
* Interview
* Rejected
* Accepted

This project demonstrates practical skills in:

* Workflow automation
* Microsoft Excel
* Power Automate
* Data management
* Process improvement
